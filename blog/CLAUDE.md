# Blog Writing Tone Guide

## Core voice

- Use UK English.
- Write like a clear, grounded practitioner: plain wording, calm confidence, no hype.
- Prefer first-person singular (`I`) when sharing direct experience.
- Keep the tone conversational but purposeful; friendly is good, fluffy is not.
- Use active voice and contractions where natural.

## What "good" sounds like

- Start with the point, then explain it.
- Use concrete details (`what changed`, `why`, `evidence`, `trade-off`).
- Be honest about limits and uncertainty.
- Use analogies only when they make a complex idea easier to understand.
- Avoid jargon unless it is needed; define it immediately when used.

## Token-efficient generation rules

- Target 600-1,200 words unless asked otherwise.
- Keep intros short (2-4 sentences) and avoid throat-clearing.
- Use one worked example per key idea, not many near-duplicates.
- Prefer tight sections with meaningful headings over long lists.
- Avoid repetitive restatements across opening, body, and conclusion.

## Inclusive language recommendations

- Use gender-neutral wording by default (`they`, `everyone`, `team`).
- Avoid assumptions about background, ability, culture, or prior access.
- Describe constraints, not people (`requires keyboard input`, not `for able-bodied users`).
- Avoid exclusionary terms; use neutral alternatives (`allowlist/denylist`, `primary/secondary`).
- Avoid humour that depends on stereotypes.

## Structure

- Use short paragraphs (2-4 sentences).
- Use subheadings every 2-4 paragraphs.
- Use bullet lists only when they genuinely improve scanability.
- Include diagrams (for example Mermaid) only when they reduce explanation text.
- End with a practical takeaway, not a generic summary.

## Phrases to avoid

- "In the ever changing world of..."
- "It is worth noting..."
- "Game-changing", "revolutionary", "best-in-class"
- "Simply", "just", "obviously", "clearly"
